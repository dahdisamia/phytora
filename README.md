# FieldGuard — حارس الحقول

منصة إرشاد زراعي للتعرف على الآفات ونشر توصيات الإدارة المتكاملة للآفات، موجهة في البداية لولاية الوادي بالجزائر، مع بنية قابلة للتوسع.

## نظرة عامة

FieldGuard تطبيق ويب تقدمي (PWA) يعمل دون اتصال بالإنترنت، يركز على:
- اختيار المحصول والمنطقة
- تشخيص موجّه بالأسئلة مع إبراز عدم اليقين
- قاعدة معرفة للآفات والأعداء الطبيعية مع مصادر موثقة
- توصيات للإدارة المتكاملة للآفات
- إحالة للحالات غير المؤكدة للخبراء
- حفظ الحالات محلياً ومزامنتها عند عودة الاتصال

## المبادئ الأساسية

- **علمي ومسؤول**: لا يتم اختراع أسماء علمية أو جرعات أو منتجات أو خبراء
- **شفاف**: عرض المصادر وتاريخ التحقق، والإشارة بوضوح لعدم اليقين
- **دون اتصال أولاً**: يمكن استخدام التشخيص وحفظ الحالات دون إنترنت
- **عربي أولاً**: واجهة عربية مع دعم فرنسي
- **فصل المحتوى عن الكود**: ملفات JSON في مجلد `content/`
- **صلاحيات حسب الدور**: مزارع / خبير / مسؤول مؤسسة / مشرف عام

## المتطلبات

- Node.js 24+
- متصفح حديث يدعم PWA

## البنية

- `src/` - واجهة React + TypeScript
- `server/` - API Express مع SQLite (node:sqlite)
- `shared/` - أنواع مشتركة ومحرك التشخيص
- `content/` - بيانات الآفات والمحاصيل والأسئلة والمصادر (قابلة للتحرير)

## قواعد البيانات والمحتوى

يستخدم المشروع SQLite لعدم توفر PostgreSQL في البيئة الحالية. تم فصل المحتوى الزراعي في `content/` ويمكن تحديثه دون تعديل كود التطبيق.

## الخصوصية والأمان

- جلسات HttpOnly
- تشفير كلمات المرور بـ scrypt
- صلاحيات على مستوى API وقاعدة البيانات
- إخفاء الإحصائيات عند أقل من 5 حالات
- عدم عرض منتجات كيميائية أو جرعات في النسخة الحالية
- عدم عرض خبراء غير موثوقين في الدليل العام
